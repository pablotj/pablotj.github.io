#  Mi Portafolio

¡Bienvenido a mi portafolio!

## 🚀 Instalación y Uso
1. Clona el repositorio:
    ```
    git clone https://github.com/pablotj/pablotj.github.io.git
    ```
2. cd mi-portafolio
3. Instala las dependencias:
    ```
    npm install
    ```
4. Inicia la aplicación:
    ```
    npm start
    ```
